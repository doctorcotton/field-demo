## 表单组件详解

`formItems` 用于定义捷径的表单 UI，以及接收用户传入的参数。目前支持以下组件：

### Input 组件

文本输入组件，用户可手动输入。

#### Props

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| placeholder | string | 输入框提示文字 |

#### execute 函数入参类型

使用 `Input` 组件时，多维表格会传递 **字符串** 给 `execute` 函数。

#### 示例代码

```typescript
import { basekit, field, FieldComponent, FieldCode } from '@lark-opdev/block-basekit-server-api';
const { t } = field;

basekit.addField({
  formItems: [
    {
      key: 'str',
      label: '请输入文本',
      component: FieldComponent.Input,
      props: {
        placeholder: 'Input组件占位符',
      },
    },
  ],
  execute: async (formItemParams, context) => {
    const { str } = formItemParams; // str 是 string 类型
    return {
      code: FieldCode.Success,
      data: str
    }
  },
});

export default basekit;
```

### SingleSelect 组件

下拉单选组件，用户手动选择下拉项里的值。

#### Props

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| placeholder | string | 输入框提示文字 |
| options | { label, value }[] | 选项数据，其中 `label` 为展示文案，`value` 为实际值 |

#### execute 函数入参类型

使用 `SingleSelect` 组件时，多维表格会传递 **`{label, value}` 对象** 给 `execute` 函数。

#### 示例代码

```typescript
import { basekit, FieldComponent, FieldCode } from '@lark-opdev/block-basekit-server-api';

basekit.addField({
  formItems: [
    {
      key: 'singleSelect',
      label: '选择水果',
      component: FieldComponent.SingleSelect,
      props: {
        options: [
          { label: '苹果', value: 'apple'},
          { label: '香蕉', value: 'banana'},
        ]
      },
    },
  ],
  execute: async (formItemParams, context) => {
    const { singleSelect } = formItemParams; // {label: '苹果', value: 'apple'}
    return {
      code: FieldCode.Success,
      data: {
        label: singleSelect.label,
        value: singleSelect.value,
      }
    }
  },
});

export default basekit;
```

### MultipleSelect 组件

下拉多选组件，用户手动选择下拉项里的值。

#### Props

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| placeholder | string | 否 | 输入框提示文字 |
| options | { label, value }[] | 是 | 选项数据，其中 `label` 为展示文案，`value` 为实际值 |

#### execute 函数入参类型

使用 `MultipleSelect` 组件时，多维表格会传递 **`{label, value}[]` 数组** 给 `execute` 函数。

#### 示例代码

```typescript
import { basekit, FieldComponent, FieldCode } from '@lark-opdev/block-basekit-server-api';

basekit.addField({
  formItems: [
    {
      key: 'multipleSelect',
      label: '选择水果',
      component: FieldComponent.MultipleSelect,
      props: {
        options: [
          { label: '苹果', value: 'apple'},
          { label: '香蕉', value: 'banana'},
        ]
      },
    },
  ],
  execute: async (formItemParams, context) => {
    const { multipleSelect } = formItemParams; // [{label: '苹果', value: 'apple'}, ...]
    const firstSelect = multipleSelect[0];
    return {
      code: FieldCode.Success,
      data: {
        label: firstSelect?.label,
        value: firstSelect?.value,
      }
    }
  },
});

export default basekit;
```

| placeholder | string | 否 | 提示文字 |
| options | { label, value }[] | 是 | 选项数据，其中 `label` 为展示文案，`value` 为实际值 |

#### execute 函数入参类型

使用 `Radio` 组件时，多维表格会传递 **`{label, value}` 对象** 给 `execute` 函数（与 SingleSelect 相同）。

### FieldSelect 组件

字段选择组件，允许用户选择多维表格中的字段作为输入。

#### Props

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| placeholder | string | 否 | 提示文字 |
| mode | 'single' | 否 | 单选模式 |
| supportType | FieldType[] | 否 | 支持哪些字段类型，比如 `[FieldType.Attachment]` 则只能选附件字段。目前只支持**文本、单选、多选、日期、附件、数字、复选框、超链接字段** |

#### 支持的字段类型

```typescript
type SupportedFieldType = 
  | FieldType.Text 
  | FieldType.Number 
  | FieldType.Url 
  | FieldType.SingleSelect 
  | FieldType.MultiSelect 
  | FieldType.Attachment 
  | FieldType.Checkbox 
  | FieldType.DateTime
```

#### 附件字段

当 `supportType` 包含 `FieldType.Attachment` 时，返回附件数组。

**类型定义**：

```typescript
type AttachmentFieldValue = {
    name: string;      // 附件名称
    size: number;      // 附件大小
    type: string;      // mime 类型
    tmp_url: string;   // 附件的临时下载地址，附件二级域名为 feishu.cn
}
```

**示例代码**：

```typescript
import { basekit, FieldType, field, FieldComponent, FieldCode } from '@lark-opdev/block-basekit-server-api';
const { t } = field;

basekit.addField({
  formItems: [
    {
      key: 'attachments',
      label: t('attachmentLabel'),
      component: FieldComponent.FieldSelect,
      props: {
        supportType: [FieldType.Attachment],
      },
      validator: {
        required: true,
      }
    },
  ],
  execute: async (formItemParams, context) => {
    const { attachments } = formItemParams; // AttachmentFieldValue[]
    const attachment = attachments?.[0];
    if (attachment) {
      return {
        code: FieldCode.Success,
        data: {
          id: attachment.tmp_url,
          name: attachment.name,
          size: attachment.size,
        },
      };
    }
    return {
      code: FieldCode.Error,
    };
  },
});

export default basekit;
```

#### 文本字段

当 `supportType` 包含 `FieldType.Text` 时，返回文本数组。

**类型定义**：

```typescript
type TextFieldValue = (ITextValue | IUrlValue | IMentionValue)[]

type ITextValue = {
    type: 'text';
    text: string;
}

type IUrlValue = {
    type: 'url';
    text: string;
    link: string;
}

type IMentionValue = {
    type: 'mention',
    text: string;
    token: string;
    link: string;
    mentionType: MentionType;
    name: string;
}

enum MentionType {
  User = 0,        // 用户
  Doc = 1,         // 文档
  Folder = 2,      // 文档路径
  Sheet = 3,       // sheet
  SheetDoc = 4,    // sheet + docs
  Chat = 5,        // 群聊
  Bitable = 8,
  Mindnote = 11,
  Box = 12,        // 飞书云文档上传的文件类型
  Wiki = 16,
  Slide = 15,
  Docx = 22,
  Slides = 30,
  Bitable_Ind = 108,
}
```

#### 数字字段

当 `supportType` 包含 `FieldType.Number` 时，返回数字。

**类型定义**：

```typescript
type NumFieldValue = number;
```

#### 日期字段

当 `supportType` 包含 `FieldType.DateTime` 时，返回时间戳。

**类型定义**：

```typescript
type DateTimeFieldValue = number; // 毫秒级时间戳
```

#### URL 字段

当 `supportType` 包含 `FieldType.Url` 时，返回超链接对象。

**类型定义**：

```typescript
type URLFieldValue = {
    link: string;
    title: string;
}
```

**注意**：超链接字段作为返回结果时，只支持输出 `title`，不支持输出 `link`。即返回超链接字段时，只能返回标题文本，无法返回链接地址。

#### 单选字段

当 `supportType` 包含 `FieldType.SingleSelect` 时，返回选项值字符串。

**类型定义**：

```typescript
type SingleSelectFieldValue = string; // 选项值
```

#### 多选字段

当 `supportType` 包含 `FieldType.MultiSelect` 时，返回选项值数组。

**类型定义**：

```typescript
type MultiSelectFieldValue = string[]; // 选项值数组
```

#### 复选框字段

当 `supportType` 包含 `FieldType.Checkbox` 时，返回布尔值。

**类型定义**：

```typescript
type CheckboxFieldValue = boolean;
```

## 返回结果类型详解

`resultType` 用于定义捷径插件返回值的类型。**注意**：在 `resultType` 中声明的类型，需要与 `execute` 函数对应的返回值类型一致，否则数据会无法写入到多维表格。

### 返回 Object 字段

对于 Object 字段，其属性字段也是在此处声明。

#### 配置属性

| 属性 | 值 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| type | FieldType.Object | 是 | 对于 Object 字段则为 FieldType.Object |
| extra | object | 是 | Object 字段的相关参数 |
| extra.icon | { light: string, dark?: string } | 是 | Object 字段主属性的图标 |
| extra.properties | object[] | 是 | Object 属性字段 |

#### properties 配置

| 属性 | 值 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| key | string | 是 | Object 属性字段的 key，从 execute 返回值取值用。例如：execute 返回值为 res，则这个字段将显示 res[key] |
| type | FieldType | 是 | Object 属性字段类型 |
| title | string | 是 | Object 属性字段的名称 |
| isGroupByKey | boolean | 否 | 标记该属性会作为 Object 字段的筛选、分组依据。⚠️ **注意**：1. `properties` 中必须有个属性的 `isGroupByKey` 为 `true`，且 type 只能为 `FieldType.Text`，该属性会作为 Object 字段的筛选、分组依据。如果返回结果中不包含此属性的字段，则不会更新 object 字段。2. 该属性在运行时的返回值没有精度要求，只要字符串长度小于 128 的即可，如果没有适合的值作为筛选和分组依据，则可以使用 `` `${Date.now()}` `` |
| primary | boolean | 否 | 标记该属性为用于排序的主属性。⚠️ **注意**：1. `properties` 数组中必须有一个 `primary` 值为 `true` 表示主属性，且主属性 type 只能为 `FieldType.Text` 或 `FieldType.Number`，且不能被隐藏。如果返回结果中不包含此属性的字段，则不会更新 object 字段 |
| hidden | boolean | 否 | 是否在字段面板中隐藏该字段，隐藏后该属性不可被新建为字段，默认为 false |
| extra.formatter | NumberFormatter | 否 | 对于数字字段，可以指定其数字格式 |
| extra.dateFormat | DateFormatter | 否 | 对于时间字段，可以指定其日期格式 |

#### 各类型对应的返回值类型

| type 类型 | 返回值类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| FieldType.Text | `string` | 文本 | `data: { text: 'xxx' }` |
| FieldType.Number | `number` | 数字 | `data: { number: 1 }` |
| FieldType.SingleSelect | `string` | 返回单选的文案 | `data: { singleSelect: 'opt_1' }` |
| FieldType.MultiSelect | `string[]` | 返回多选的文案数组 | `data: { multiSelect: ['opt_1'] }` |
| FieldType.DateTime | `number` | UNIX 时间戳（毫秒） | `data: { date: 1234567890123 }` |
| FieldType.Checkbox | `boolean` | 布尔值 | `data: { checkbox: true }` |

#### 示例代码

```typescript
import { basekit, FieldType, field, FieldComponent, FieldCode, NumberFormatter } from '@lark-opdev/block-basekit-server-api';
const { t } = field;

basekit.addField({
  resultType: {
    type: FieldType.Object,
    extra: {
      icon: {
        light: 'https://example.com/icon.svg',
      },
      properties: [
        {
          key: 'id',
          type: FieldType.Text,
          title: 'id',
          isGroupByKey: true,  // 必须有一个 isGroupByKey 为 true
          hidden: true,
        },
        {
          key: 'name',
          type: FieldType.Text,
          title: t('name'),
          primary: true,  // 必须有一个 primary 为 true
        },
        {
          key: 'amount',
          type: FieldType.Number,
          title: t('amount'),
          extra: {
            formatter: NumberFormatter.DIGITAL_ROUNDED_2,
          }
        },
      ],
    },
  },
  execute: async (formItemParams, context) => {
    return {
      code: FieldCode.Success,
      data: {
        id: `${Date.now()}`,
        name: '示例名称',
        amount: 123.45,
      }
    };
  },
});

export default basekit;
```

### 返回附件字段

返回附件字段时，`data` 必须是附件数组。

#### 类型定义

```typescript
type AttachmentResultType = {
    code: FieldCode;
    data: {
        name: string;              // 附件名称，需要带有文件格式后缀
        content: string;           // 可通过 http.Get 请求直接下载的 url
        contentType: "attachment/url";  // 固定值
        width?: number;            // 选填，图片宽度
        height?: number;           // 选填，图片高度
    }[];
}
```

#### 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 附件名称，需要带有文件格式后缀 |
| contentType | string | "attachment/url"（固定值） |
| content | string | 附件下载地址，必须是公共资源。**数量限制为 5 个附件，单个附件的大小限制为 10M** |
| width | number | 选填，图片宽度 |
| height | number | 选填，图片高度 |

#### 示例代码

```typescript
import { basekit, FieldType, field, FieldComponent, FieldCode } from '@lark-opdev/block-basekit-server-api';

basekit.addField({
  formItems: [
    {
      key: 'urls',
      label: '选择URL',
      component: FieldComponent.FieldSelect,
      props: {
        supportType: [FieldType.Text],
      },
    }
  ],
  resultType: {
    type: FieldType.Attachment,
  },
  execute: async (formItemParams, context) => {
    return {
      code: FieldCode.Success,
      data: [
        {
          name: "ex.png",
          content: "https://example.com/image.png",
          contentType: "attachment/url",
          width: 800,
          height: 1200,
        }
      ],
    };
  },
});

export default basekit;
```

### 返回单选字段

返回单选字段时，`data` 必须是字符串（选项名称）。

#### 配置属性

| 属性 | 值 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| type | FieldType.SingleSelect | 是 | 声明返回为单选字段 |
| extra | object | 是 | 单选字段的相关参数 |
| extra.options | {name: string}[] | 是 | 单选字段的预设选项 |

#### 示例代码

```typescript
import { basekit, FieldType, FieldComponent, FieldCode } from '@lark-opdev/block-basekit-server-api';

basekit.addField({
  formItems: [
    {
      key: 'account',

      validator: {
        required: true,
      }
    },

  resultType: {
    type: FieldType.SingleSelect,  // 定义捷径的返回结果类型为单选字段
    extra: {
      options: [
        { name: '预设选项1' },
        { name: '预设选项2' }
      ]
    }
  },

      code: FieldCode.Success,

    }

```

## execute 函数详解

`execute` 定义捷径插件的运行逻辑，目前仅支持 Node.js。

### execute 入参

`execute` 函数包含以下入参：

#### formItemParams

实际运行时用户传入的参数，该对象的 `key` 会与 `formItems` 中定义的 key 值保持一致，value 与 `formItems` 中各种组件定义的结构一致。

**示例**：

```json
{
    "textKey": "文本值",
    "numberKey": 1.23,
    "numbersKey": [1.23, 1.24]  // numbersKey 配置的 mode 为 multiple
}
```

#### context

每次调用的上下文对象，包含以下属性：

| 参数 | 类型 | 示例值 | 说明 |
| --- | --- | --- | --- |
| fetch | (url, options, authorizationId) => Promise<Response> | - | 请求外部的数据的 API |
| baseSignature | string | eyJzb3V... | 签名数据，与 packID 配合使用，可以在服务端验证请求是否来自此捷径，详见 [高级功能 - 捷径流量标识](./高级功能.md#捷径流量标识) |
| baseID | string | 7395539782238404612 | 多维表格的 id，仅用于区分多维表格，无法通过此 id 定位到某一具体多维表格 |
| logID | string | 02172524652697100000000000000000000fffff9bbf0be4d73cd | 可用于报错的时候协助排查错误日志 |
| tableID | string | tblvoVgvLtYumGeq | 数据表中的表格 id |
| packID | string | replit_3e4ce893726c23e4 | 捷径上线后的唯一标识。可以与 baseSignature 配合使用，供开发者服务端验证流量来源 |
| tenantKey | string | 11a1b11208c8575e | 租户 id，可用于计费 |
| timeZone | string | Asia/Shanghai | 时区 |
| baseOwnerID | string | ou_e04138c9633dd0d2ea166d79f54abcef | 文档 owner 用户在捷径字段场景下的唯一标识 |
| hasQuota | boolean | true | 付费权益，用于判断用户是否有权限使用该捷径 |

### execute 返回值

`execute` 必须要有一个返回值，通过 `code` 告知多维表格运行结果，通过 `data` 返回数据。

#### 返回值结构

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `FieldCode` | `execute` 执行结果 `code`，具体值见下方的 `code` 定义。请使用 code 来向用户抛出错误，而不是 msg |
| `data` | 根据 resultType 定义 | 根据定义的返回结果(resultType)，返回对应的数据结构值。Object 字段，根据返回结果的定义返回对应的属性值，其中 id 和主属性是必填值 |
| `msg` | `string` | `execute` 执行错误信息，仅用于 feishu 内部用户查日志 debug，不会向使用者暴露，可以一些特殊格式开头以方便查日志 debug，比如：'===捷径代码主动返回错误:....'。请严格遵循 code 的规则来向用户抛出错误 |

#### 示例代码

```typescript
import { basekit, FieldCode } from '@lark-opdev/block-basekit-server-api';

basekit.addField({
    execute: async function(formItemParams, context) {
        return {
            code: FieldCode.Success,
            data: {
                id: "id1", 
                primaryProperty: "prim1",  // 主属性，只能是 number 或 string
                property1: "value1",  // key 是返回结果定义的 properties 中的 key
                property2: 234  // value 结构要与返回结果定义的 properties 中的 type 对应的返回值类型一致
            },
            msg: '',
        };
    },
});
```

### 错误码（FieldCode）

| code 值 | 含义 |
| --- | --- |
| FieldCode.Success | 运行成功 |
| FieldCode.ConfigError | 配置错误，即用户在配置面板选择的值不合法可以返回该错误码 |
| FieldCode.AuthorizationError | 授权错误 |
| FieldCode.PayError | 付费错误异常 |
| FieldCode.RateLimit | 限流 |
| FieldCode.QuotaExhausted | quota 耗尽 |
| FieldCode.InvalidArgument | 参数错误，用户所选配置的内容合法，但是代码中未兼容等情况 |
| FieldCode.Error | 插件运行失败（如果前面的 code 值都不符合，才考虑使用通用的报错 code） |

### 请求外部数据（fetch）

你可以通过 `context` 中注入的 `fetch` 方法请求外部数据，`fetch` 语法见 [node-fetch](https://github.com/node-fetch/node-fetch)。

#### 域名白名单

**注意**：需要在插件调用 `basekit.addDomainList` 声明所需发起网络请求的域名白名单，向不在白名单内的域名请求会被拒绝！

**配置规则**：

- 所填写域名需包含主机名（如 example.com），可打开其子域名（如 doc.example.com）
- 域名可以使用 IP 地址（支持 IPV4 和 IPV6）或 localhost
- 不支持配置端口
- 仅支持填写域名，带上协议、路径会导致匹配失败

**示例代码**：

```typescript
// 声明域名白名单，向不在白名单内的域名请求会被拒绝
basekit.addDomainList(['example.com']);  // 可以打开 https://doc.example.com, https://img.example.com

basekit.addDomainList(['localhost']);  // 可以打开 http://localhost:{{port}}，其中任意端口号都可以访问

basekit.addDomainList(['192.168.1.1']);  // 可以打开 http://192.168.1.1:{{port}}，其中任意端口号都可以访问

// ❌ 错误示例
basekit.addDomainList(['https://example.com']);  // 带上了协议会导致无法正确识别域名
basekit.addDomainList(['example.com/', 'example.com/path']);  // 带上了路径会导致无法正确识别域名
```

**重要**：`basekit.addDomainList` 只能调用一次，多次调用会被覆盖！

#### fetch 使用示例

```typescript
basekit.addDomainList(['example.api.com']);

basekit.addField({
    execute: async function(formItemParams, context) {
        const { fetch } = context;
        
        // 发起带 Query 的请求文本数据
        const query = new URLSearchParams({
            foo: 'bar',
        });
        
        // 发起 GET 请求 text 数据
        const textRes = await fetch(`https://example.api.com?${query.toString()}`);
        const textData = await textRes.text();
        
        // 发起 POST 请求 json 数据
        const jsonRes = await fetch('https://example.api.com', {
            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({
                foo: 'bar',
            }),
        });
        const jsonData = await jsonRes.json();
        
        return {
            code: FieldCode.Success,
            data: jsonData
        };
    },
    ...
});
```

#### 使用授权

如果配置了授权，可以在 `fetch` 的第三个参数中传入授权 id：

```typescript
// 通过指定 context.fetch 第 3 个参数为授权 id：auth_id_1
const res = await context.fetch(url, {
    method: 'POST',
}, 'auth_id_1');  // 第三个参数为某个授权的 id
```

详细授权配置请参考 [高级功能 - 授权配置](./高级功能.md#授权配置)。

#### 模式1：使用 debugLog（简单直接）

```typescript
execute: async (formItemParams: { account: number }, context) => {
  // 日志工具
  function debugLog(arg: any, showContext = false) {
    if (!showContext) {
      console.log(JSON.stringify({ arg, logID: context.logID }), '\n');
      return;
    }
    console.log(JSON.stringify({
      formItemParams,
      context,
      arg

  }

  // 入口第一行日志，展示 formItemParams 和 context，方便调试
  // 每次修改版本时，都需要修改日志版本号，方便定位问题
  debugLog('=====start=====v1', true);

  // fetch 封装
  const fetch: <T = Object>(
    ...arg: Parameters<typeof context.fetch>
  ) => Promise<T | { code: number, error: any }> = async (url, init, authId) => {
    try {
      const res = await context.fetch(url, init, authId);
      const resText = await res.text();  // 先转换为文本，避免直接 .json() 解析失败

        [`===fetch res： ${url} 接口返回结果`]: {
          url, init, authId,

        }
      });

    } catch (e) {
      debugLog({
        [`===fetch error： ${url} 接口返回错误`]: {
          url, init, authId, error: e
        }
      });
      return { code: -1, error: e };
    }
  };

  try {
    // 业务逻辑
    const res = await fetch<ExchangeRateResponse>('https://api.exchangerate-api.com/v4/latest/CNY');
    const usdRate = res?.rates?.['USD'];
    
    return {
      code: FieldCode.Success,
      data: {
        id: `${Math.random()}`,
        usd: parseFloat((formItemParams.account * usdRate).toFixed(4)),
        rate: usdRate,
      }
    };
  } catch (e) {
    debugLog({ '===999 异常错误': String(e) });
    return {
      code: FieldCode.Error,
    };
  }
},
});
```
